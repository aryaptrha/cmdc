ALIZA / machine conversation instrument

Nothing you type leaves this page. There is no model and no network call: only a keyword table and a substitution list.

01 / Context

It never understood anything.

The 1966 script scanned a sentence for keywords, took the strongest match, and returned the remainder as a question with the pronouns reversed. That is the entire mechanism. There is no model, no memory worth the name, and no representation of meaning.

It is reproduced here rather than explained, because the reproduction is the argument. Every reply you receive below comes from a rule you can read in the next section.

02 / The script

Five steps, in order.

  1. Tokenise the input on whitespace and punctuation.
  2. Rank every keyword found. Highest rank wins; ties go to the keyword that appears earliest.
  3. Take the words after that keyword and reverse the pronouns so the sentence returns to you.
  4. Emit the next response in that keyword's list.
  5. When nothing matches at all, rotate through a short list of generic prompts.

03 / After

Where it breaks.

Try a sentence with no keyword. Try a subordinate clause. Try the same sentence twice and watch it cycle. The failures are the clearest evidence that nothing is understood — the machine is reflecting your own words back at you and nothing more.
